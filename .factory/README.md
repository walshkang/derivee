# .factory

Workspace directory for wave execution contracts, schemas, and receipts.
- schemas/: Machine-readable schemas defining execution protocols.
- active_brief.json: Wave contract written by orchestrator before execution.
- receipt.json: Structured execution receipt returned upon wave completion.
- diffs/: Wave patch files (<wave_id>.patch) for verification and audit.
- scratch/: Ephemeral wave logs and temporary diagnostics.
